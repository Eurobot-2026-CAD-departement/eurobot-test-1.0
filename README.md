# Eurobot test 1.0

CAD of the robot **after the ENSI competition**.

We changed the wheels to **JSUMO wheels** and paired them with **Pololu motors** for more grip and speed, as needed for the navigation testing phase. (Note: this was done well before the main Eurobot robot was built, during the brainstorming and prototyping phase.)

## Contents
- `eurobot test 1.0.SLDASM` — full assembly
- `base test after ensi.SLDPRT` / `.DXF` — the updated base
- `piece util/` — reusable parts (motors, wheels, ...) used by this design

Thank you for your attention to this file!
